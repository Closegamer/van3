# Опциональные скрипты первичной инициализации

Файлы **`.sql`** / **`.sh`** в этом каталоге выполняются контейнером PostgreSQL **один раз** при создании **нового** тома данных.

Чтобы использовать их, раскомментируйте монтирование в **`docker-compose.yml`**:

```yaml
- ./docker/initdb:/docker-entrypoint-initdb.d:ro
```

Затем пересоздайте том (см. **DEPLOY.md**, раздел «Сброс данных»), если база уже была поднята без initdb.
